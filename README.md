TaxiTimer
==================
A simple addon that adds flight time to the taxi map. Note that the timer can be a bit off as the addon is in its early stages of development.

You can type `/taxitimer mode` to customize how the timer behaves:
- `stopwatch` (previous default)
- `bar` (default)
- `details` (bar with additional information)
- `none` (no timer)

The bar can be dragged if you hold down Shift.
